# CourtVision

Find candidate player-contact moments in basketball clips using pose estimation, and review them in a frame-accurate viewer.

> **Status:** in progress. See [docs/devlog.md](docs/devlog.md) for how it's being built.

CourtVision highlights *where contact may have occurred*. It does not decide whether a foul took place.
